# Kids games

Interactive HTML games/exercises for an 8-year-old.
Sites (personal account, `*.workers.dev`; old https://keeper-fun-games.surge.sh redirects to the first):
- `keeper-fun-games` — main site, Ukrainian (`SITE_LANG=uk`).
- `keeper-fun-games-es` — Spanish site for Spanish friends (`SITE_LANG=es`, wrangler `--env es`): same code, same assets, same D1 (users/progress shared).

## Child context
- Native language: Ukrainian. Goes to a Spanish school. Learning English.
- Interests: football.

## Structure
- `index.html` + `catalog.js` — catalog (game list, coins, football-card album with packs, achievements).
- `games/<slug>/` — one game per folder, no build step: `index.html` (markup + inline CSS), `game.js` (game code, classic script, IIFE),
  optional `content.js` (data), `art.js` (drawings), `engine.js` (pure logic with unit tests). No inline `<script>` blocks (tsc/Biome can't check them).
- `shared/kf.js` — progress core (`window.KF`): coins, cards/packs, achievements, game registry `KF.GAMES`.
- `shared/cards.js` + `images/cards/` — card manifest and WebP images, generated by
  `python3 -I scripts/build-cards.py <dir> [<dir>...]` (dirs with source PNGs, the md list in any of them; images and the source zips in `images/cards/` are not in git; `deploy.sh` rebuilds missing images from all the zips; the zips are never deployed).
- `shared/exam/` — exam-prep engine (`window.KFExam`): `exam.js` (`mount(unit, { art, types, weight?, onAnswer? })` — optional `task.key`, task weights, answer hook; renders hub, intro dialog, rounds, exam with cards, finish, records, keys;
  `validate(unit, types?)`), `types.js` (renderers choice/tf/sort/order/pairs), `exam.css`; unit shape in `types/exam.d.ts` (`ExamUnit`), renderer contract = `ExamRendererCtx`.
- `games/sociales-planeta/` — the first exam unit: `content.js` (data), `types.js` (own task types mapTap/label/paint/walk), `art.js` (drawings), `game.js` (one `KFExam.mount` line).
- `games/sociales-planeta/maps.js` — world + Spain SVG paths from Natural Earth (public domain), generated by
  `node scripts/build-sp-maps.mjs <work-dir>` (GeoJSON + `polygon-clipping` live in the work dir outside the repo; setup in the script header).
- `audio/en/*.mp3` + `shared/audio.js` (`window.KF_AUDIO` manifest) — pre-recorded neural TTS clips of the English words, generated and committed via `EDGE_TTS=~/.cache/kf-tts/bin/edge-tts node scripts/build-audio.mjs` (setup/options in the script header); deployed.
- `shared/kf-ui.js`, `shared/kf.css` — shared look + toasts for coins/achievements.
- `shared/site.js` — `window.KF_SITE = { lang }`; static default `uk`, the Worker answers it itself (`es` on the Spanish site). Loaded before `cards.js`/`kf.js` on every page.
- `worker/`, `migrations/`, `wrangler.jsonc` — backend (users with PIN, progress sync, results) — see `BACKEND.md`.

## Conventions
- Big buttons, works offline after load.
- Minimal scrolling: on laptops (from 1280×650) a play screen — task, controls, feedback + next button — fits without page scroll
  (two columns on wide-and-short screens, feedback beside/over the work area, art sized to the free height); on phones scroll as little as possible.
- Every game must work both with touch (tablet/phone) and laptop keyboard + mouse:
  number/letter keys for input, Enter = submit, Backspace = erase, Esc = back/close, arrows/1–4 for choices;
  visible focus, hover states, no swipe-only or hover-only actions.
- UI text: Ukrainian by default; tasks may mix UA/ES/EN on purpose (see IDEAS.md).
- Short rounds (2–5 min), instant feedback, celebrate wins, no punishment for mistakes.
- Every game: include `../../shared/kf.css`, `cards.js`, `kf.js`, `kf-ui.js`, `kf-game.js`; call `KF.answer(slug, correct)` per answer
  and `KF.finishGame(slug, { score, max })` at round end; add a "back to catalog" link (`../../`).
- Rewards must not be farmable: pay less for easy content (`KF.answer(slug, ok, { coin: 0.5 })`, `finishGame(..., { bonus })`)
  and pay the perfect-round bonus only until a level is done perfectly once. Every game's coins pass a daily budget in
  `KF` (40 a day per game in full, then a third; a toast suggests another game). Own coin rules go through `KF.earn(slug, n)`.
- Shared game helpers: `shared/kf-game.js` (`KFG`: $, h, shuffle, pick, screens, dots, feedback, keys, confirm, say/canSay/speaking/preload = speech: a clip from `shared/audio.js` when the text has one (include it before kf-game.js), else a local voice, silent without one) — include after kf-ui.js; use them instead of re-implementing.
- New exam unit (school subject/unit): folder `games/<slug>/` with `index.html` (copy the `sociales-planeta` stub: `exam.css` link, unit `<style>` only for what is unit-specific, `<main id="exam-root">`, scripts incl. `shared/exam/exam.js`+`types.js`),
  `content.js` (`window.<NAME> = ` an `ExamUnit`: slug = folder, stations with tasks, `exam.perStation`; optional `strings`/`lists`/`hues`/`sampling`/`round`) and `game.js` (`KFExam.mount(unit, { art, types })`);
  only for task types beyond choice/tf/sort/order/pairs add `types.js` (renderers `(task, work, ctx)`) and `art.js`. Then `KF.GAMES` entry (`beta`), run `tests/unit/exam-content.test.mjs` (add the unit there), add an e2e spec (see `exam-engine.spec.mjs`: a content-only unit via `page.route`).
- New game → add entry to `GAMES` in `shared/kf.js`: `beta` while in progress (visible only in test mode), then `ready`.
- Language: `KF.lang` (`'uk' | 'es'`, from `KF_SITE`; never use hostname/`navigator.language`). `?lang=es` / `?lang=uk` forces it in the tab (like `?parent`), `?lang=off` drops it.
  Texts: `const T = KF.i18n({ uk: {...}, es: {...} })`, `T('key', { n })`, `T.apply()` for `[data-i18n*]`; missing es key → uk. The uk dictionary keeps today's exact text. Spanish site: Spain Spanish, «tú», no Cyrillic.
- `GAMES` entries have `sites: ['uk']` or `['uk','es']` and `es: { title, desc }`; catalog uses `KF.siteGames()` (filtered by `KF.lang`, title/desc in that language).
- Move a game to the Spanish site: translate its dictionary (`KF.i18n({ uk, es })`, no Cyrillic on `?lang=es`), add `'es'` to its `sites`, check `tests/unit/i18n.test.mjs`.
- Test mode for parents: any page with `?parent` (off: `?parent=off`) — per-tab sandbox progress (100 coins), real progress untouched.
- Progress: guest = localStorage only; logged-in user = local copy synced to D1 in the background (offline-first).
  Games keep using the synchronous `KF` API and never call the network themselves.
- Users are added by hand: `node scripts/add-user.mjs <name> <pin> [avatar]` (`--update` changes the PIN).

## Tests
- Code style: Biome (`biome.json`); `pnpm format` fixes formatting + safe lint fixes, `pnpm lint` checks.
- Types: `pnpm typecheck` (tsc, checkJs, no build; part of `pnpm test`). Cross-file globals (`KF`, `KFUI`, `MathExam`, …) are declared in `types/*.d.ts` (`kf.d.ts`, `kf-game.d.ts`, `exam.d.ts`; never put a `.d.ts` next to a same-named `.js` — tsc then skips the `.js`); new files must type-check (no `@ts-nocheck` in new code).
- `pnpm install` once, then `pnpm test` = lint + unit (`node --test`, `tests/unit/`) + Playwright e2e (`tests/e2e/`, system Chrome, `playwright.config.mjs`; `tests/serve.mjs` serves the repo on :8795).
  Parts: `pnpm test:unit`, `pnpm test:e2e [spec] [--project=laptop|phone]`. Every run is in `?parent` mode with a seeded `Math.random`; any console/page error fails a test.
- Unit: kf.js (i18n, sync/merge, daily coin budget), math-exam and coach-simon engines, exam content (`KFExam.validate`). E2E: catalog, one spec per game, `keyboard` (laptop), `no-scroll` (laptop 1366×657), `rewards`, `screenshots` (phone; refresh with `--update-snapshots` after an intended UI change).
- `deploy.sh` runs `pnpm test` first and aborts on failure.
- New game → add an e2e spec that plays one full round to the finish screen (plus `?lang=es` if it is on the Spanish site) and a keyboard test.

## Publish
- `./deploy.sh` — `pnpm test`, remote D1 migrations (retried up to 3×) + `wrangler deploy` + `wrangler deploy --env es` (both sites) (static files from the root, exclusions in `.assetsignore`;
  `books/` must never be uploaded). Needs `wrangler login` to the personal account (`account_id` in `wrangler.jsonc`).
- Local: `wrangler dev --local --persist-to ~/.cache/kf-wrangler-state --port 8790 > ~/.cache/kf-dev.log 2>&1` (Spanish: add `--env es`, other port)
  (logs must go outside the project, otherwise the asset watcher reload-loops).
